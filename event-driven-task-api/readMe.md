🎯 Project Goal

Build a Task Management REST API where actions like creating, updating, or completing tasks trigger events using Node.js EventEmitter.

You will learn:

Event-driven architecture

Node.js + Express project structure

MySQL integration

Service layer architecture

SOLID-friendly structure

Real-world backend patterns

🧱 Features

Create Task

Get All Tasks

Get Task by ID

Update Task

Delete Task

Mark Task as Completed

Emit events on:

task.created

task.updated

task.completed

task.deleted

Log events in console (later extendable to email, notification, audit logs)

🛠 Tech Stack

Node.js

Express.js

MySQL

EventEmitter (built-in)

mysql2

dotenv
